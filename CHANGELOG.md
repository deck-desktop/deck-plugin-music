# Changelog

## 1.4.0 (2026-11-12)

- Listen together: invite a Deck team, or one person in it, to hear what you play as you play it.
  Whoever invited controls playback; each listener has their own volume. Asks for the network
  permission.
- Play on the track already loaded starts it again.

## 1.3.0 (2026-11-01)

- Runs on Linux: downloads use python3 and the folder's own separator. Needs Deck 1.15.0.

## 1.2.1 (2026-10-30)

- A licence, this changelog, a README rewritten with a screenshot, and the permissions it uses
  declared. Built from its own lockfile.

## 1.2.0 (2026-10-18)

- The first version in Deck's plugin registry.
